# Playbooks

Métodos que **ya han demostrado funcionar** y están `approved`.

Está vacío a propósito. Un playbook se escribe cuando un método se ha
repetido con éxito y el usuario lo ha dado por bueno, no para rellenar la
carpeta.

Front matter obligatorio: `type: playbook`, `status: approved`, `origin`,
`created`, `validated_by`, `area`. `brain-check` rechaza cualquier
playbook que no esté `approved`.
